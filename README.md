#Number Guessing Game

▪ Description:-

This is a Python-based Number Guessing Game developed as part of the Synent Technologies Python Development Internship.

The game randomly selects a number between 1 and 100, and the player has to guess the correct number with the help of hints.

✦ Features:-

- Random number generation
- Number range from 1 to 100
- Higher and lower hints
- Attempt counter
- Invalid input handling
- Out-of-range input handling
- User-friendly command-line interface

◆ Technology Used:-

- Python
- Random module

➤ How to Run:-

1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the following command:

   number_guessing_game.py

4. Enter a number between 1 and 100.
5. Follow the hints and continue guessing until you find the correct number.

★ Objective:-

To develop a simple Python-based Number Guessing Game that uses random number generation, loops, conditional statements, and exception handling.
